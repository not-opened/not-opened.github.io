# notopened.com

## 연결

- 꿈풀이: `/fortune/?tab=dream`
- 사주: `/fortune/`
- MBTI 궁합: `/fortune/?tab=mbti`
- 상식 퀴즈: `/quiz/`
- 바둑·체스 한 수: `/go-chess/`
- 유튜브: [youtube.com/@notopened](https://www.youtube.com/@notopened)
- 블로그: [blog.naver.com/penta309](https://blog.naver.com/penta309)

커스텀 도메인과 HTTPS는 이 저장소의 Pages 설정에서 따로 켭니다.
